# Solar System

A dark theme for the Claude desktop and mobile apps with a slowly moving solar system behind the conversation. Every planet, the asteroid belt, the Kuiper belt and Pluto are drawn with their real semi-major axes, eccentricities and periods, all on one time scale where an Earth year lasts 60 seconds. Distances and sizes are not to scale, and every orbit is drawn flat, so Pluto's 17 degree tilt is not shown.
