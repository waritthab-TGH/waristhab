# Laniakea Night

A night-sky theme for the Claude desktop and mobile apps. Deep-space blue surfaces, starlight text and a gold accent, over a slowly moving backdrop: twinkling stars, flow lines of the Laniakea supercluster converging on the Great Attractor, the basin boundary, and labels for Virgo, Hydra-Centaurus, Pavo-Indus and the Milky Way. Dark mode only. Terminals and editors draw no theme.

## Install

Claude Code 2.1.275 or later, at the prompt of a terminal session:

```
/plugin install laniakea-night --marketplace waritthab-TGH/waristhab
```

Answer `y` to add the marketplace, then pick a scope.

Older versions, from a shell:

```
claude plugin marketplace add waritthab-TGH/waristhab
claude plugin install laniakea-night@laniakea-night
```

Newer versions, from a shell:

```
claude plugin install laniakea-night --marketplace waritthab-TGH/waristhab
```

The flow lines are an artistic simulation, not measured peculiar-velocity data.
